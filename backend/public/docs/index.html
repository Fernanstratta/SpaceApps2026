Starman API

Build planet cards, Earth analog maps, and Earth–Moon or Earth–Mars comparisons with public, read-only JSON endpoints.

Start locally

With Node.js 24, run Vercel from the repository root to serve the app and API on the same origin.

npm ci
npm run dev:vercel

Choose an endpoint

  • Build an Earth map
  • Explore nine lunar comparison axes
  • Compare a curated Earth–Mars pair
  • Find source records and credits

Use the Vercel deployment origin in production. No API key is required. The eight regional handlers support an optional CORS allowlist. Serve the docs from the backend origin to try every route in your browser.
